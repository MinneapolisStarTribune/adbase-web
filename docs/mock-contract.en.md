# Synthetic Forecasting Contract

Date: 2026-11-17

These choices make the application and tests executable without a database or Entra ID. They are provisional test behavior, not assertions about the existing stored procedures or approved financial rules.

| Area               | Synthetic behavior                                                                                                                                                                                                                                                                                                                                    |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Data ownership     | One in-memory repository per process; no external calls or persistence. Restart resets all changes.                                                                                                                                                                                                                                                   |
| Reference data     | JSON metadata defines years, territories, products, optional advertiser-specific availability, and account scopes.                                                                                                                                                                                                                                    |
| Search             | Six-digit advertiser IDs are strings. Numeric search is an exact ID match; other search is a case-insensitive name substring. Nonempty search overrides the range. `#` means a name whose first character is not A–Z.                                                                                                                                 |
| Pagination         | 30 rows per page, sorted by advertiser name and record ID. Requests past the last page clamp to the last page.                                                                                                                                                                                                                                        |
| Total              | Sum all twelve months for all records in the selected territory/year, ignoring advertiser search, range, and pagination.                                                                                                                                                                                                                              |
| Amounts            | Decimal strings; commas and surrounding whitespace are removed, blanks become zero. Negative and all-zero records are allowed. Sample input accepts up to 14 integer and 4 fractional digits, without exponents. Invalid months reject the entire save. Display keeps stored fractional digits.                                                       |
| Creation           | Advertiser must belong to the selected territory; product must be available for the territory/year and advertiser. Duplicate advertiser/territory/product/year combinations return 409.                                                                                                                                                               |
| Editing            | Stable internal record ID plus expected version. Only the twelve amounts can change. Stale versions return 409. User and timestamp are supplied on the server.                                                                                                                                                                                        |
| Advertisers        | Exactly six ASCII digits; trimmed name of 1–500 characters; valid territory; duplicate ID and stale version checks apply to creation/editing.                                                                                                                                                                                                         |
| Advertiser history | ID/territory changes are blocked when forecasts reference the advertiser, pending a history policy. Unlinked advertisers may move or change ID. Renaming changes the master entry; existing forecast name snapshots remain unchanged.                                                                                                                 |
| Export scope       | All forecast fixtures in the current process, independent of page filters. The future stored procedure determines the real scope.                                                                                                                                                                                                                     |
| CSV                | UTF-8, comma delimiter, CRLF record separators, quoted special characters, fixed eight-column header; advertiser 999999 and zero months are excluded. Export date is UTC `YYYY-MM-DD`. Formula protection applies to free-text fields, not validated negative numeric amounts. Real Domo consumers must approve date/encoding/text-escaping behavior. |
| Sample identity    | Explicit local account picker; no credentials. 256-bit opaque session token in an HttpOnly, SameSite=Strict cookie; Secure on HTTPS. Server stores token hashes, not raw tokens.                                                                                                                                                                      |
| Session lifecycle  | 30-minute idle and 8-hour absolute limits for this sample only. Login rotates the previous session; logout revokes it. Production time limits and a shared store remain integration decisions.                                                                                                                                                        |
| Audit              | UTC timestamp, stable actor ID, operation, outcome, optional resource ID and server-generated correlation ID. Business events go to structured stdout and the in-memory event sink; the activity page shows the latest 100 events to administrators.                                                                                                  |

## Permission matrix

| Operation               | Representative       | Delegate                           | Administrator   | Unassigned |
| ----------------------- | -------------------- | ---------------------------------- | --------------- | ---------- |
| Query, totals, choices  | Assigned territories | Assigned and delegated territories | All territories | Denied     |
| Create/update forecasts | Assigned territories | Assigned and delegated territories | All territories | Denied     |
| Advertiser maintenance  | Denied               | Denied                             | Allowed         | Denied     |
| Domo download           | Denied               | Denied                             | Allowed         | Denied     |
| Activity view           | Denied               | Denied                             | Allowed         | Denied     |

All business APIs require a valid session. Missing/expired sessions return 401, denied access 403, invalid input 400, absent records 404, and duplicate/stale writes 409. Mutations also require the expected Origin and JSON content type. Sample identity selection is available only while mock mode passes environment validation; production rejects it.

The in-memory session store has a replaceable interface. Multi-instance sessions, durable audit history, transactional SQL behavior and database round-trip precision cannot be validated by this mock implementation. The team must confirm those during the excluded integration work.
